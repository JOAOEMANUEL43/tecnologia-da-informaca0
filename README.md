# LLM Renderizado

Material explicativo sobre o conceito de **LLM Renderizado** (Rendered LLM) — o processo de formatar e exibir a saída de um modelo de linguagem grande de forma visual e estruturada.

## Conteúdo

- `O-que-e-LLM-renderizado.md` — explicação em Markdown
- `O-que-e-LLM-renderizado.html` — versão em HTML com estética Glinda (tema rosa brilhante)

## O que é LLM Renderizado?

Um **LLM Renderizado** é um modelo de linguagem grande cuja saída é processada e formatada antes de ser apresentada ao usuário final, transformando texto bruto em conteúdo legível e estruturado (títulos, listas, código formatado, etc.).

## Como visualizar

Abra o arquivo `O-que-e-LLM-renderizado.html` em qualquer navegador.
